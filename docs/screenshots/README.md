## Screenshot Guidelines

### Capture Settings
- **Resolution**: 1920x1080 or higher
- **DPI**: 96 DPI (standard)
- **Format**: PNG (lossless)
- **Color Space**: sRGB

### Content Guidelines
- Use representative content (not empty screens)
- Include realistic file names and project structure
- Show actual features being used (not just UI chrome)
- Avoid personal information or sensitive data
- Use consistent theme across all screenshots

### File Naming
- Use lowercase with hyphens
- Descriptive names (not `screenshot1.png`)
- Include feature area prefix where applicable
- Examples:
  - `git-commit-dialog.png`
  - `mcp-query-results-table.png`
  - `ai-assistant-chat.png`

### Tools
- **Windows**: Win + Shift + S (Snipping Tool)
- **macOS**: Cmd + Shift + 4
- **Linux**: GNOME Screenshot, Spectacle, Flameshot
