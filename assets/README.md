# Speckit Editor Icons and Assets

This directory contains icons and visual assets for the Speckit Editor application.

## Directory Structure

- `icons/` - Application icons for different platforms and sizes
- `images/` - UI images and graphics
- `themes/` - Theme resources

## Icon Sizes

For proper cross-platform support, provide icons in multiple sizes:

- **Windows**: 16x16, 32x32, 48x48, 256x256
- **macOS**: 16x16, 32x32, 128x128, 256x256, 512x512
- **Linux**: 16x16, 22x22, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256

## Placeholders

Currently using placeholder icons. Production icons will be created in Task T016.

## Icon Format

- Use PNG format with transparency for application icons
- Use SVG format where possible for UI icons (scalable)
- Optimize images for file size while maintaining quality
